# Octopus — публичная часть

Здесь лежит только то, что скачивает пользователь: **описания сборок** и сами
**сборки** модулей. Исходного кода здесь нет и не будет — он в приватном
репозитории.

Репозиторий существует по технической причине: `raw.githubusercontent.com` и
GitHub Releases отдают файлы анонимно только из публичных репозиториев, а
открывать репозиторий с кодом ради этого нельзя.

## Что где

| Путь | Что это |
|---|---|
| `versions/<модуль>.json` | описание опубликованной сборки: версия, адрес архива, контрольная сумма, путь к исполняемому файлу |
| `api.json` | адрес серверной прослойки — чтобы её переезд не требовал пересборки лаунчера |
| Releases | сами архивы сборок |

## Описание сборки

```json
{
  "version": "1.0.0",
  "archive": "https://github.com/wasone1/octopus-user/releases/download/fishing-1.0.0/OctopusFishing-1.0.0.zip",
  "sha256": "…",
  "exe": "OctopusFishing/OctopusFishing.exe"
}
```

Лаунчер сверяет `sha256` **до** распаковки и отказывается ставить архив, чей
хэш не совпал. Поле обязательно: описание без него не считается описанием.

## Что публичность отсюда не даёт

Скачать архив может кто угодно — и это нормально. Модуль без окна подписки не
ловит: право работать выдаёт сервер, а не наличие файла на диске. Запуск в
обход лаунчера даёт окно с надписью «запускайте через Octopus» и ничего больше.
